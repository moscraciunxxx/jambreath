# JamBreath — Devpost

## Tagline

Turn live TomTom jams into idle-CO2 estimates and healthier do-not-sit-in-it moves.

## Elevator pitch

Congestion is an air and climate problem. JamBreath listens to TomTom traffic, estimates idle CO2 from delay, checks corridor AQI, and nudges you toward leave-later, alternate route, or skip-the-queue — with a session impact ledger.

## Built with

- TypeScript
- Vite
- Vitest
- TomTom Traffic / Routing APIs (optional live key; fixture demo without)
- Open-Meteo Air Quality
- GitHub Pages

## Demo

https://moscraciunxxx.github.io/jambreath/

## What is unique

- Fixture mode so judges can run without an API key
- Explicit 20 g/min ESTIMATE idle CO2 (not greenwashed LCA)
- Session ledger for delay and CO2 avoided when you pick a healthier action
